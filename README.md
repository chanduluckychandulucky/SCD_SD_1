# README.md 🌡️

## Temperature Converter Website

This is a simple **Temperature Converter** web application built using **HTML, CSS, and JavaScript**.
It converts temperatures between:

* Celsius (°C)
* Fahrenheit (°F)
* Kelvin (K)

---

## Features ✨

* Easy-to-use interface
* Instant temperature conversion
* Supports all three temperature scales
* Responsive and clean design
* Built with pure HTML, CSS, and JavaScript

---

## Technologies Used 💻

* HTML5
* CSS3
* JavaScript

---

## How to Run 🚀

1. Copy the code into a file named `index.html`
2. Save the file
3. Open the file in any web browser
